# hxyfront-62006 珠宝镶嵌宝石分拣

面向珠宝镶嵌工作室的**可提交分批工作流**：按尺寸建批 → 逐颗归类 → 校验提交 → 锁定/撤回，全程留痕、刷新不丢。

## 工作流规则

1. **建批先按尺寸筛选**：新建批次时选择尺寸区间（围石料 2.1–3.5mm / 主石料 ≥4mm / 配石料 ≤2.0mm / 自定义），只有落在区间内、且尚未入批的宝石会被收入批次；批次内还可再次按尺寸筛选子集。
2. **四种去向**：每颗宝石必须归到 **主石 / 围石 / 配石 / 退回待定** 之一。
3. **容量限制**：主石位限 **1** 颗、围石位限 **8** 颗（配石与退回待定不限量）。
4. **整批拒绝 + 标出冲突**：提交时若存在「未定去向」或主石/围石位「超容」，整批拒绝、不锁定；拒绝横幅逐类列出并标出宝石编号，表格中对应宝石标红「冲突」，可勾选「只看冲突」快速处理。
5. **提交锁定**：校验通过后批次锁定，去向不可再改（示意图显示锁定标记）。
6. **撤回留痕**：撤回后恢复分拣中，**原去向和每次调整记录全部保留**，并追加一条撤回记录（含原提交时间）。
7. **刷新可继续**：所有批次、去向、锁定状态、调整记录均持久化在 `localStorage`。

## 界面组成

- 左侧：批次列表 + 按尺寸新建批次（显示料盘剩余宝石数）
- 右侧工作区：容量卡片（主石 / 围石 / 配石 / 待定 / 未定 / 总克拉）、镶嵌位置示意图（中心主石位 + 外圈 8 围石位）、批次内尺寸筛选与冲突过滤、宝石明细表（含缺陷备注）、调整记录时间线

## 技术栈

React 19 + Vite + TypeScript，无后端，数据存于浏览器 localStorage。
